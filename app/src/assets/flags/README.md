# Flag SVGs

Circular country flags for the Settings › Language screen.

Source: [circle-flags](https://github.com/HatScripts/circle-flags) by HatScripts, MIT
licensed. Each file is the unmodified 512×512 circular SVG copied from that set.

| File | Country | Shown for |
|------|---------|-----------|
| `us.svg` | United States | English (`en`) |
| `ae.svg` | United Arab Emirates | Arabic (`ar`) |
| `pk.svg` | Pakistan | Urdu (`ur`) |
| `in.svg` | India | Hindi (`hi`) |

English and Arabic don't map to a single country; US and UAE are a deliberate
choice. The code → flag mapping lives in `app/src/app/flags.ts`.
